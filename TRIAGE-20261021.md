## Known failures not fixed here (all present at baseline)

Environment or host:
- Xcode license is not accepted on this Mac. `macos-sysroot-native`,
  `signing-resources`, `hud-modifier-native` and root `desktop-builder` need the
  native toolchain. No license was accepted and no toolchain was changed.
- `stage-native-deps.test.mjs` asserts Linux compiler-failure wording, so it
  should be gated to Linux.
- `data-paths.test.ts` assumes a short `HOME`. The isolated long `HOME`
  correctly triggers the SSH socket fallback, so the test should mock a short
  homedir.
- `remote-lifecycle.test.ts` installer-wrapper ownership: macOS has no `/proc`,
  and `ps` loses argv boundaries for paths with spaces. Checks were not loosened.
  This needs a dedicated investigation.
- `updater/checkout-source.test.ts` and root `update-ui` timed out under
  suite load. `checkout-source` passed in the after run, so it looks
  load-sensitive.
- Python CI routing replay needs Bash 4 (`mapfile`), but macOS ships Bash 3.2.
  Prompt-inventory generation imports a Linux sysconfig module on macOS.

Canonical-path fixture defects (`/tmp` vs `/private/tmp`). These follow the
same pattern as the fixes above but were left out of scope:
- `electron/desktop-uninstall.test.ts` (3 cases),
  `scripts/prepared-native-deps.test.mjs`, `tests-js/node-deps.test.mjs`
  (2), `tests-js/product-builders.test.mjs` (2).
- TUI `coldPendingRenderer.test.tsx` (2) and
  `submissionDestinationRenderer.test.tsx` (1) build raw `/tmp` homes, but
  production canonicalizes them. Canonicalize the fixtures. Do not weaken the
  identity checks.

Untriaged: `npm ci --prefix website` reported 33 audit findings (3 low, 30
high). These were not verified, and no dependencies were changed.
